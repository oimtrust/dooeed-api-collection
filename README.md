# API Collection — Bruno

## Import the collection

1. Download and install [Bruno](https://www.usebruno.com/downloads).
2. Clone or download the repository containing the API collection. If downloaded as a ZIP file, extract it first.
3. Open Bruno and choose **Open Collection**.
4. Select the collection folder containing `bruno.json` (or `opencollection.yml` for YAML collections), then open it. Select the folder itself, rather than an individual request file.
5. Confirm that the collection and its requests appear in the sidebar.

## Import an exported collection

If you received an exported collection file instead of a folder:

1. Open Bruno and click **+ → Import Collection**.
2. Choose the format that matches your file, then browse for or drag in the exported collection.
3. Follow the prompts to choose a destination folder, if requested, and click **Import**.
4. Confirm that the imported requests appear in the sidebar.

See the [official Bruno import guide](https://docs.usebruno.com/get-started/import-export-data/import-collections) for more details.
